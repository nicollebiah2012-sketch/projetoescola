# Mapa da Comunidade

PWA para o projeto escolar.

## Funcionalidades

- Cadastro de nome, cidade e bairro.
- Mapa do Brasil.
- Registro de reclamações.
- Endereço da reclamação.
- Pin vermelho para cada reclamação.
- Geolocalização dos endereços.
- PWA instalável.
- Layout responsivo.
- Armazenamento local.

## Tecnologias

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap
- Nominatim
- Service Worker

## Vercel

O projeto não precisa de build.

Framework Preset:

Other

Build Command:

vazio

Output Directory:

vazio

## Observação

Esta versão salva os dados apenas no navegador do usuário.

Para que todos os usuários compartilhem as mesmas reclamações e pins, será necessário adicionar um banco de dados e um backend.
